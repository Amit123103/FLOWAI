# FlowAI

Premium AI developer workspace landing page.

## Overview

FlowAI is a fictional AI developer workspace created as a frontend
product design and engineering assessment.

## Features

- Premium responsive landing page
- Interactive dashboard
- Workflow interaction
- Product capability demonstrations
- Interactive code preview
- Responsive mobile navigation
- Accessible UI
- Production-ready build

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Deployment

Deploy using Vercel.

## Important

This project uses demonstration data and does not represent
real FlowAI customers, users, statistics, or production metrics.
